
-> Configuració Sysmon desde powershell

1) Change "include" to "exclude"
2) sysmon.exe -c filename.xml

----

-> Arxiu .etx generat per Event Tracing for Windows. Aquest arxiu et proporciona informació més detallada sobre els events recolectats. El tipus d'event a recolectar s'especifica amb les opcions de la comanda.

-----

-> Filtrar els events mitjançant XML Querys:

Excloure events amb el seguent nom d'Imatge:

*[EventData[Data[@Name='Image']!='C:\Windows\System32\WindowsPowerShell\v1.0\powershell.exe']] --> Es modifica el Name="" i la ruta.
